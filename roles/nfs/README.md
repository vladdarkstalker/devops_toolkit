# Роль `nfs`

Роль находится в разработке и пока не разворачивает NFS-сервер или клиент. Текущие `defaults`, `tasks` и `handlers` являются структурными заготовками и не должны считаться рабочей автоматизацией.

Планируемое назначение и критерии готовности перечислены в [`docs/ROADMAP.md`](../../docs/ROADMAP.md).
